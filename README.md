# Outcome Context — case-study prototype

A clickable, mobile-first prototype of **Outcome Context**: a quiet moment inside a Groww-like investing app that helps a first-time investor interpret their *first IPO listing outcome* — without recommending, predicting or judging.

Open `index.html` in any browser (no build step). On desktop it renders inside a phone frame; on a phone it goes full-bleed.

**Flow:** Portfolio → IPO holding → Outcome Context → Reflection → Portfolio.
**Demo controls** (left panel / top strip on mobile): switch between the **Gain (+24.8%)** and **Loss (−12.4%)** scenarios, jump to any step, or restart.

Principles: interpret, don't recommend · separate outcome from decision quality · gain and loss screens are structurally identical · Buy/Sell are never blocked · "Not now" is always available.

All figures are illustrative mock data; nothing here is investment advice or a claim about real user behaviour.
